# Ручная проверка кластеризации карты

Автоматические Django-тесты проверяют данные и подключение ресурсов, но не
интерактивность OpenLayers. Следующие сценарии выполняет пользователь в браузере
на приватной карте `/photos/` и публичной карте `/public/<username>/`.

1. **Пустая карта:** нет JS-ошибок, сохраняется сообщение об отсутствии фотографий.
2. **Один маркер:** прежний значок, цвет публичности и увеличение выбранного
   маркера. Popup показывает фото, дату, место, погоду и сравнение с нормой.
   Lightbox открывается, закрывается кнопкой, фоном и Escape.
3. **Разделимый кластер:** разместить несколько фото поблизости, уменьшить масштаб.
   Число в синем круге соответствует количеству фото. Нажатие плавно приближает
   карту до разделения на группы/маркеры. Колесо, кнопки zoom, двойной клик,
   перетаскивание и pinch продолжают работать. Повторить рядом с максимальным zoom.
4. **Одинаковые и очень близкие координаты:** кластер, который не распадётся даже
   на максимальном zoom, сразу показывает галерею без бесполезного приближения.
   Проверить как одинаковые GPS, так и разные координаты с разницей менее пикселя
   при максимальном масштабе; все фото должны быть доступны.
5. **Галерея:** заголовок с количеством, все изображения без имён файлов,
   новые даты сначала, неизвестные даты в конце, равные даты упорядочены по id.
   Навести курсор: title содержит дату съёмки в виде `06.06.2026, 13:26`;
   у фото без taken_at — «Дата съёмки неизвестна», а не дата загрузки.
6. **Выбор фото:** каждая миниатюра одним нажатием закрывает галерею и открывает
   соответствующий прежний popup; lightbox, погода и дата выбранного фото работают.
   На приватной карте работают изменение и удаление; после удаления число в
   кластере обновляется. Переход с `/photos/?photo_id=<id>` открывает нужное фото,
   включая фото внутри кластера.
7. **Закрытие:** кнопка ✕, Escape, клик по пустой карте/другому маркеру/кластеру,
   перемещение и изменение масштаба закрывают галерею. Управление клавиатурой:
   Tab до миниатюры, Enter для выбора; после Escape/✕ фокус возвращается карте.
8. **Много фото:** десятки фотографий в одной точке — галерея прокручивается,
   заголовок и закрытие доступны, все миниатюры выбираются, карта не масштабируется
   колесом при прокрутке галереи.
9. **Mobile:** ширина 320–390 px, портретная и альбомная ориентации, touch/pinch.
   Нет горизонтальной прокрутки, галерея помещается, даты под миниатюрами видны
   без hover, нажатие сразу выбирает фото. Кнопки карты и навигация доступны.
10. **Приватность:** публичное и приватное фото владельца в одной точке плюс фото
    другого пользователя. Анонимная публичная карта показывает только публичные
    фото указанного владельца, включая число в кластере и содержимое галереи.

## Реализация и границы

Используется OpenLayers 10.2.1, `ol.source.Cluster`, расстояние 52 CSS px.
Для решения о приближении тот же алгоритм проверяет исходные точки кластера
при допустимых разрешениях View, включая максимальный zoom. Если разделения
нет, открывается одна общая галерея; иначе анимация идёт к первому целому zoom,
на котором появляются группы (либо к максимальному, если он дробный).
Промежуточные группы с неразделимыми фото также можно открыть в галерее.

GeoJSON дополнен nullable-полем `taken_at_display`: форматирование непосредственно
из taken_at, без timezone-преобразования, как у прежнего поля date, но без
подстановки uploaded_at. Прежние поля и правила доступа сохранены.
Модель хранит taken_at как datetime; отдельной точности «только дата» в ней нет.
Галерея также умеет вывести строку только с датой без добавления времени.
Используются существующие image_url с lazy loading, отдельные thumbnails
не создаются. Для большого кластера это может означать загрузку крупных файлов.
